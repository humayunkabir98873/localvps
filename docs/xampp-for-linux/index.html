An XAMPP for Linux alternative with PHP 8.4, nginx and MariaDB

LocalVPS gives Linux developers what XAMPP's lampp used to: one folder, one control panel, every site on its own name.localhost address. It uses your distribution's maintained packages and current PHP.

Where XAMPP for Linux stands

As of October 2026, apachefriends.org no longer lists a Linux download. The newest xampp-linux-x64 installer in its SourceForge folder is PHP 8.2.12 from November 2023. It ships its own copies of Apache, OpenSSL and MySQL libraries under /opt/lampp, which your distribution never updates.

How LocalVPS does it differently

Instead of bundling its own binaries, LocalVPS uses the nginx, php-fpm and MariaDB packages your distribution keeps patched. Then it runs its own instances of them, as your user, with its own configs, ports and data folder.

  • Debian, Ubuntu, Mint, Pop!_OS (apt): PHP 8.2, 8.3, 8.4 and 8.5 side by side via the ondrej/php PPA or packages.sury.org.
  • Fedora (dnf) and Arch (pacman): the distribution's default PHP.
  • No root at runtime: sites use port 8080 by default, because Linux reserves ports below 1024 for root.
  • No surprise services: the install command switches off the system-wide nginx, MariaDB and php-fpm services so they don't hold ports 80 and 3306.
  • Node.js: the official nodejs.org build (SHA-256 checked) for Next.js and npm.

Install

  1. Download LocalVPS-…-linux-x64.tar.gz from Releases (needs glibc 2.35+, e.g. Ubuntu 22.04 or Debian 12 and newer).
  2. Extract and start it: 
    tar -xzf LocalVPS-*-linux-x64.tar.gz
cd LocalVPS
./localvps
  3. Click Install recommended stack. LocalVPS types one sudo command into its built-in terminal, for example: 
    sudo apt-get install -y nginx php8.4-fpm php8.4-mysql … mariadb-server
sudo systemctl disable --now nginx php8.4-fpm mariadb
    Press Enter, type your password, then click Detect installed.
  4. Create a site and open http://your-site.localhost:8080.

Want clean URLs on port 80? Allow it once with sudo setcap cap_net_bind_service=+ep /usr/sbin/nginx and set the HTTP port to 80 in Settings.

Questions

Why doesn't LocalVPS bundle its own PHP like XAMPP did?

Distribution packages get security updates through your normal system updates. A bundled copy goes stale, as XAMPP's Linux build did.

Can I keep using /opt/lampp?

Yes, on different ports. Or move your projects over: copy /opt/lampp/htdocs/project into a LocalVPS site and import the database. See the migration guide.

Does it work in WSL?

It should: WSL runs a normal Ubuntu or Debian, and the Linux package is built for those. It hasn't been tested there yet. On Windows itself, the Windows package needs no WSL at all.
