An XAMPP for Mac alternative with PHP 8.4, nginx and MariaDB

If you searched for "XAMPP for Mac" and found old PHP versions, you're not imagining it. LocalVPS is a free, open-source local server for Apple Silicon Macs with current PHP, one address per site, and a control panel in your browser.

What happened to XAMPP on macOS?

As of October 2026, the download page on apachefriends.org offers Windows builds only. The newest macOS installer in XAMPP's SourceForge folder is PHP 8.2.4, published in April 2023. PHP 8.2 receives security fixes only until the end of 2026, and PHP 8.3, 8.4 and 8.5 have no macOS build.

XAMPP for Windows is still updated. The Mac and Linux editions appear to have stopped.

How LocalVPS runs on a Mac

Apple Silicon needs native arm64 binaries, and Homebrew already maintains them for PHP, nginx and MariaDB. LocalVPS installs those formulae with brew install from its control panel. It then runs its own copies with its own configs, ports and data folder, so it doesn't touch any brew services setup you already have.

  • PHP: php (8.5), php@8.4, php@8.3 and php@8.2 side by side, each as its own php-fpm pool. You choose one per site.
  • Web server: nginx serves every site at http://name.localhost. macOS allows port 80 without root, so URLs stay clean.
  • Database: MariaDB LTS (11.8 by default) with a generated root password and one user per site.
  • Node.js: the official nodejs.org build (SHA-256 checked) for Next.js sites and npm.

Install

  1. Install Homebrew if you don't have it.
  2. Download LocalVPS-…-macos-arm64.tar.gz from Releases and extract it.
  3. In Terminal, in that folder: 
    xattr -dr com.apple.quarantine .   # first run only: the build is not notarized
./localvps
  4. In the panel that opens, click Install recommended stack, then create a site.

Intel Macs: there's no prebuilt Intel package yet. Run LocalVPS from source instead (git clone, npm install, ./start.sh); it works the same.

Questions

Do I need to uninstall XAMPP first?

No. If XAMPP's Apache or MySQL is running, change LocalVPS's ports in Settings (e.g. 8080 and 3307) or stop XAMPP.

Will it change my existing Homebrew services?

No. LocalVPS starts its own processes with its own config and data under its folder. Formulae it installs are shared with Homebrew like any other.

Does Valet or Herd conflict with it?

Only on ports. Valet uses dnsmasq for .test; LocalVPS uses .localhost, which macOS browsers already resolve to your machine.
