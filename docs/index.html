The free XAMPP alternative for Windows, macOS and Linux

LocalVPS runs nginx, PHP 8.2–8.5, MariaDB and Node.js for you, gives every project its own address like my-app.localhost, and ships it to a real VPS when you're ready. A modern control panel replaces the config files.

Everything a local PHP server should do in 2026

One hostname per site

Every project gets name.localhost automatically. There are no hosts-file edits, no vhost files, and no admin rights needed.

PHP version per site

Install PHP 8.2, 8.3, 8.4 and 8.5 side by side and pick one for each site. Switch with a dropdown.

WordPress, Laravel, Next.js

One-click templates create the files, the database and the config, so wp-config.php and .env are ready to use.

Database manager

Create databases and users, run SQL, and import or export .sql dumps. MariaDB gets a random root password, not an empty one.

Terminal in the browser

A real shell in each site's folder with php, composer, npm and mariadb on the PATH, plus quick commands for artisan and npm.

Deploy to a real VPS

Export a bundle, or deploy over SSH to Ubuntu or Debian. The script installs nginx, PHP and MariaDB on the server, imports your database and can set up HTTPS.

Up and running in three steps

  1. Download and start. Unzip and double-click LocalVPS.exe on Windows, or run ./localvps on macOS and Linux. The control panel opens in your browser.
  2. Install the stack. Click Install recommended stack. Windows gets official builds. Mac gets them from Homebrew, and Linux from your package manager (you confirm the sudo command).
  3. Create a site. Pick Blank PHP, WordPress, Laravel or Next.js, then open http://your-site.localhost.

Moving existing projects over? Follow the XAMPP to LocalVPS migration guide.

Frequently asked questions

Is LocalVPS free?

Yes. It's open source under the MIT license, with no paid tier and no account required.

Is there an XAMPP for Mac with PHP 8.4?

The official XAMPP download page no longer lists macOS, and the newest macOS build on its SourceForge mirror is PHP 8.2.4 from April 2023. LocalVPS runs on Apple Silicon Macs with current PHP from Homebrew. See LocalVPS on Mac.

Does LocalVPS work on Linux?

Yes: Ubuntu, Debian and other apt systems with PHP 8.2–8.5, plus Fedora (dnf) and Arch (pacman) with their default PHP. Sites use port 8080 by default, so no root is needed. See LocalVPS on Linux.

Can I use it without internet?

Yes, once the stack is installed. Internet is only needed to download components and site templates.

Which is better: WAMP, XAMPP or LocalVPS?

WAMP and XAMPP bundle Apache with a single PHP version. LocalVPS uses nginx, gives each site its own PHP version and hostname, and exports sites to a real server. Pick what matches how you deploy.

Can I run XAMPP and LocalVPS at the same time?

Yes, if they use different ports. Set LocalVPS's HTTP and MariaDB ports in Settings, for example 8080 and 3307.
