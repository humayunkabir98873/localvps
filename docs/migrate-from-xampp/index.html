How to migrate from XAMPP to LocalVPS

Each XAMPP project becomes its own LocalVPS site with its own address, PHP version and database user. Plan about five minutes per project. You can keep XAMPP installed while you move.

Before you start: avoid port clashes

XAMPP's Apache uses port 80 and its MySQL uses 3306, the same as LocalVPS on Windows and macOS. Either stop Apache and MySQL in the XAMPP Control Panel, or in LocalVPS go to Settings and set the HTTP port to 8080 and the MariaDB port to 3307.

1. Export each database from XAMPP

In XAMPP's phpMyAdmin, open the database and use Export → Quick → SQL. Or use the command line:

# Windows
C:\xampp\mysql\bin\mysqldump.exe -u root --routines --triggers my_db > my_db.sql
# Linux
/opt/lampp/bin/mysqldump -u root --routines --triggers my_db > my_db.sql

XAMPP's MySQL is MariaDB, so the dump imports into LocalVPS's MariaDB unchanged.

2. Create the site in LocalVPS

  1. Open Sites → New site, choose Blank PHP, name it (e.g. shop), and tick Create a MySQL database and user.
  2. Copy your project from C:\xampp\htdocs\shop (or /opt/lampp/htdocs/shop) into www/shop/public, replacing the sample index.php.
  3. If the project's web root is a subfolder (Laravel's public/, for example), copy the whole project into www/shop and set Web root in the site's Settings.

3. Import the database

On the Databases page, select the site's database (shop_db), click the import button and choose my_db.sql. The site's credentials are shown in its Settings.

4. Point the app at the new database

  • Plain PHP: use host 127.0.0.1 and the site's user and password instead of root with no password. LocalVPS also writes them to www/shop/db.local.php.
  • Laravel: update DB_HOST, DB_DATABASE, DB_USERNAME and DB_PASSWORD in .env, and set APP_URL=http://shop.localhost.
  • WordPress: update DB_NAME, DB_USER, DB_PASSWORD and DB_HOST in wp-config.php, then replace the old URL in the database. In the site's Terminal: 
    curl -sO https://raw.githubusercontent.com/wp-cli/builds/gh-pages/phar/wp-cli.phar
php wp-cli.phar --path=public search-replace "http://localhost/shop" "http://shop.localhost" --all-tables

5. Open it

Visit http://shop.localhost (or http://shop.localhost:8080 on Linux or if you changed the port). If PHP errors appear, check Logs → php-8.4.log. Older projects may need a different PHP version, which you can pick in the site's Settings.

Common differences from XAMPP

My .htaccess rewrites don't work

LocalVPS uses nginx, which ignores .htaccess. Front-controller apps (Laravel, WordPress, most frameworks) work out of the box. Custom rules go in the site's Extra nginx directives.

Where is phpMyAdmin?

The Databases page covers the everyday tasks: create, drop, SQL console, import and export. If you prefer phpMyAdmin, create a Blank PHP site and unzip phpMyAdmin into its public folder.

Sendmail and FTP are missing

LocalVPS leaves out XAMPP's mail and FTP servers. For mail testing, point your app's SMTP settings at a tool like Mailpit.
